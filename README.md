# Detecção de Phishing em Websites
## Sobre o Projeto

Este projeto tem como objetivo aplicar e comparar quatro algoritmos de classificação supervisionada na identificação de websites fraudulentos (phishing) e websites legítimos, utilizando a base de dados pública Phishing Websites.

O trabalho é desenvolvido na disciplina de Ciência de Dados, da Universidade Federal de Uberlândia (UFU), no semestre 2026/2.

## Objetivos
Realizar a análise exploratória da base de dados.
Identificar características relevantes para a detecção de phishing.
Aplicar técnicas de pré-processamento e transformação dos dados.
Implementar quatro algoritmos de classificação supervisionada.
Testar diferentes configurações de parâmetros para cada algoritmo.
Avaliar e comparar os resultados obtidos.
Identificar o algoritmo com melhor desempenho na classificação.

## O desenvolvimento do projeto será dividido nas seguintes etapas:

Exploração dos dados: análise das características, atributos, distribuição das classes e identificação de inconsistências.
Pré-processamento: tratamento de dados ausentes, duplicatas e preparação dos atributos.
Implementação: aplicação de quatro algoritmos de classificação supervisionada.
Parametrização: execução de pelo menos duas configurações diferentes para cada algoritmo.
Avaliação: utilização de métricas como acurácia, precisão, recall e F1-score.
Comparação: análise dos resultados e identificação do modelo mais adequado.
Métricas de Avaliação
Acurácia (Accuracy)
Precisão (Precision)
Revocação (Recall)
F1-Score
Matriz de Confusão
